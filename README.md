## 📌 Описание проекта

«Очищено!» — это функциональный прототип веб-приложения, помогающий пользователям легко и правильно сортировать мусор с помощью компьютерного зрения.

### 🎯 Цель проекта
Создать удобный веб-сервис, который по фотографии автоматически определяет тип отходов (пластик, стекло, бумага, металл, органика.), и подсказывает, в какой именно бак/контейнер их необходимо выбросить.

### 💡 Ключевой функционал:
* 📷 Загрузка и обработка фото: Загрузка изображения любого предмета (бутылка, газета, баночка и т.д.) через веб-интерфейс.
* 🤖 Нейросетевое распознавание: Определение категорий отходов с помощью модели машинного обучения и визуализация объектов.
* ♻️ Интерактивная подсказка: Рекомендации по маркировке и правильному контейнеру для сбора.
